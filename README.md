## 发布和复建

本目录可直接作为现有 GitHub Pages 的 main 分支根目录发布，保留 `.nojekyll`。早期原始质量子集可从完整开发目录重新构建（它不包含本次无损扩容）：

```sh
python scripts/build-pages-release.py --source /workspace/phigros --output /workspace/phigros-pages-release --max-bytes 990000000
```

输出必须为新的空目录。脚本不会修改完整开发目录；它按歌曲整体选择资源，过滤目录并验证所有引用，生成 `assets/meta/pages-release.json` 和实际覆盖报告。Pages 平台总上限以其当时规则为准；此脚本使用小于十进制 1GB 的站点文件预算。

无损扩容使用 `scripts/build-lossless-catalog-art.py` 准备并逐像素校验曲绘，再运行 `scripts/expand-pages-catalog.py --prepare-charts-only` 生成谱面缓存，最后运行 `scripts/expand-pages-catalog.py` 生成独立暂存目录。需要完整开发资源及脚本默认路径中的媒体索引和谱面缓存；输出不会直接修改发布目录。

所有新谱面已在完整资源构建中通过现有解析器和原始字节哈希检查；此发布另核对每个被引用文件都存在且长度符合清单。音频校验报告覆盖完整开发资源库，发布只是选择原文件子集。浏览器真机及官方客户端逐曲／逐帧对照尚未进行。


本次扩容保留所有已发布歌曲及成绩标识；谱面仅重新 gzip 压缩，解压后的 JSON 字节不变。高清原图以逐像素校验相同的无损 WebP 存储，原 PNG 保留于完整开发资源库，音乐不重编码。旧聚合谱面包由已存在的 individual 文件取代，发布清单同步更新；游玩、导出和离线备份仍使用同一资源索引。扩容报告见 `assets/meta/lossless-expansion.json`。

## 联网曲库候选

本站保留 162 个歌曲／版本及 492 张谱面。另有 173 个版本、572 张谱面标为“联网”：进入歌曲时从固定提交的 GitHub 原始资源读取，失败时尝试同一固定提交的 jsDelivr 备用；下载后校验字节数和 SHA-256。联网曲目依赖外部网络及 OGG Vorbis 播放能力，旧版 iOS Safari 可能不支持，不能当作离线曲目。本站资源不依赖外站。
