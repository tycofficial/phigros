## Older Safari audio compatibility

The music directory adds 173 existing AAC compatibility derivatives (109,437,991 bytes), associated with exact original OGG hashes in music-index.json. Original upstream OGG files remain unchanged and remain the playback/export source on supported browsers. These lossy AAC derivatives are used only when the browser cannot play the original Vorbis audio. Song authorship is retained by the main catalog.

The Rr_Unlock.mp4 scene is distinct from TimeReverse_Video.mp4 and is used after the interactive clock corridor. Original clip SHA256: 671e2862af83d5629aad91cfc764a4bd419f79e0f3f6a34fd7a581da1a7a17d6. Historical modified archive provenance is preserved beside the clip.
